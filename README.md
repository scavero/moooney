# moooney

App de finanzas personales con IA local. Analiza los extractos exportados desde el banco (Santander) sin enviar datos a ningún servicio externo.

## Datos

Los extractos (`.xls`, `.xlsx`, `.csv`) van en `data/excel/`. Esa carpeta está ignorada por git: **ningún dato bancario se sube al repositorio**.
